=== LAYOUT SYSTEM (App.tsx) ===
3-tier responsive layout:

< 881px (mobile):
  - Single column, full width main content
  - Left sidebar → slides out as LEFT DRAWER (triggered by ☰ in Header)
  - Right sidebar → slides out as RIGHT DRAWER (triggered by SlidersHorizontal icon next to mobile search bar)
  - Search bar breaks to full-width second row below header

881px – 1299px (tablet):
  - flex-row layout
  - Main content: flex-1 min-w-0 (fills remaining width)
  - Right sidebar: fixed width w-[400px] / min-[1100px]:w-[430px], shrink-0
  - Left sidebar hidden (use left drawer)

≥ 1300px (desktop):
  - CSS grid: 10 columns total
  - Left sidebar: col-span-3
  - Main content: col-span-4
  - Right sidebar: col-span-3

=== DRAWER PATTERN ===
Both drawers in App.tsx use:
  - Fixed overlay backdrop: fixed inset-0 bg-slate-900/50 z-40
  - Slide panel: fixed top-0 [left|right]-0 h-full z-50
  - Transition: translate-x-0 (open) vs -translate-x-full / translate-x-full (closed)
  - isInDrawer={true} prop → strips ALL rounded corners inside sidebar components

=== ESCROW BUY FLOW ===
1. User opens ListingDetailModal → clicks "Buy Now via Escrow"
2. Checkout sub-modal opens inside ListingDetailModal
3. User enters shipping address → confirms → onBuyNow(listing, shippingAddress) called
4. Order created with status: 'escrow_held', escrowStatus: 'held'
5. Tracked in OrdersView

=== COMMON PITFALLS ===
- Right sidebar squishing: use shrink-0 + fixed pixel width, NOT grid fractions
- Modal clipped on mobile: outer overlay needs overflow-y-auto + flex items-start justify-center py-6
- Drawer conflict: Left drawer breakpoint = 1300px | Right drawer breakpoint = 881px
- Search bar + drawer button height mismatch: use h-10 on both + items-stretch on parent flex
