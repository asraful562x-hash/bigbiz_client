## 1. DATABASE SCHEMA & CASCADE DELETE CONSTRAINTS

All child tables in PostgreSQL have explicit `OnDelete:CASCADE` and `OnUpdate:CASCADE` constraints configured. Deleting a parent `Product` (or parent `ProductCustomOptionSection` / `ProductCustomOptionSubSection`) automatically cleans up and deletes all dependent rows across all relational tables.

### Table 1: `products` (Product Core Table)
- **Fields**:
  - `id`: uint (Primary Key, Auto Increment)
  - `user_id`: uint (Foreign Key -> `users.id`, Indexed)
  - `title`: varchar(255) (Product Title / Listing Name, Not Null)
  - `description`: text (Product Description)
  - `price`: decimal(10,2) (Base Price, Not Null, Default: 0.00)
  - `discount_rate`: decimal(5,2) (Discount Rate Percentage: 1.00 - 99.00, Default: 0.00)
  - `create_date_time`: timestamp (`autoCreateTime`)
  - `update_date_time`: timestamp (`autoUpdateTime`)

```go
type Product struct {
	ID             uint      `gorm:"primaryKey;autoIncrement" json:"id"`
	UserID         uint      `gorm:"not null;index" json:"user_id"`
	Title          string    `gorm:"type:varchar(255);not null" json:"title"`
	Description    string    `gorm:"type:text" json:"description"`
	Price          float64   `gorm:"type:decimal(10,2);not null;default:0.00" json:"price"`
	DiscountRate   float64   `gorm:"type:decimal(5,2);default:0.00" json:"discount_rate"`
	CreateDateTime time.Time `gorm:"autoCreateTime" json:"create_date_time"`
	UpdateDateTime time.Time `gorm:"autoUpdateTime" json:"update_date_time"`

	// Relational Associations (On Delete Cascade)
	User                  User                            `gorm:"foreignKey:UserID;references:ID" json:"user,omitempty"`
	MarketplaceCategories []ProductMarketplaceCategoryMap `gorm:"foreignKey:ProductID;references:ID;constraint:OnUpdate:CASCADE,OnDelete:CASCADE;" json:"marketplace_categories,omitempty"`
	UserCategories        []ProductUserBaseCategoryMap    `gorm:"foreignKey:ProductID;references:ID;constraint:OnUpdate:CASCADE,OnDelete:CASCADE;" json:"user_categories,omitempty"`
	Variants              []ProductVariant                `gorm:"foreignKey:ProductID;references:ID;constraint:OnUpdate:CASCADE,OnDelete:CASCADE;" json:"variants,omitempty"`
	OptionSections        []ProductCustomOptionSection    `gorm:"foreignKey:ProductID;references:ID;constraint:OnUpdate:CASCADE,OnDelete:CASCADE;" json:"option_sections,omitempty"`
	Keywords              []ProductKeyword                `gorm:"foreignKey:ProductID;references:ID;constraint:OnUpdate:CASCADE,OnDelete:CASCADE;" json:"keywords,omitempty"`
}
```

## 2. DUAL-MODE IMAGE UPLOAD IN CLIENT FORM

The product creation form (`src/components/listing-create/ImageGalleryUploader.tsx`) supports two methods for adding images:

1. **Local File Input (Browse & Drag/Drop)**:
   - Accepts PNG, JPG, WEBP formats (multiple files supported).
   - Reads files as base64 and pre-uploads directly to Cloudinary via `POST /api/posts/upload`.
   - Displays animated spinner during CDN upload and displays thumbnail when done.

2. **Web URL Input**:
   - Accepts any external image URL (e.g. Unsplash, CDN, Shopify).
   - Direct inclusion with "Enter" key shortcut.

3. **Gallery Management**:
   - First image automatically becomes the primary cover.
   - Any thumbnail can be promoted to cover via "Make Cover" button or removed via "Delete" button.

## 3. CRUD API SUMMARY

- `POST /api/products`: Creates product + category maps + variants + option sections + keywords.
- `GET /api/products`: Returns products with full preloads. Supports `?user_id=X` & `?search=term`.
- `GET /api/products/:id`: Returns single product.
- `PUT /api/products/:id`: Updates product fields and re-syncs relations.
- `DELETE /api/products/:id`: Deletes parent product; PostgreSQL cascade automatically removes all child mappings, variants, options, and keywords.
